This section walks you from **access and prerequisites** through **first deployment** and **hands-on notebooks**.

Typical order:

1. [Get your API key](/2-get-started/authentication-and-api-keys) (NGC / API access as required by your workflow).
2. Confirm the [Pre-Requisites & Support Matrix](/2-get-started/pre-requisites-support-matrix) for your OS, GPU, and software stack.
3. Choose a path in [Deployment options](/3-deployment-options/compare-deployment-options) — local library, hosted NIMs, the Helm chart for Kubernetes, or a standalone Docker service.
4. Explore [Jupyter Notebooks](https://github.com/NVIDIA/NeMo-Retriever/blob/main/examples/README.md) for end-to-end examples.

The NeMo Retriever Library and its Helm chart are not supported under NVIDIA AI Enterprise (NVAIE). For more information, refer to [NVIDIA AI Enterprise (NVAIE) support](/1-introduction/what-is-nemo-retriever#nvidia-ai-enterprise-nvaie-support).

If you are new to the product, read [What is NeMo Retriever Library?](/1-introduction/what-is-nemo-retriever) and [Concepts](/1-introduction/key-concepts) under **Introduction** first.
